# AI Squat Trainer

This repository contains a Windows-based AI squat trainer application that uses MediaPipe and OpenCV to provide real-time squat feedback.

## Files
- `squat_trainer.py` - main desktop application script
- `squat_trainer (1).py` - original script copy
- `app.py` - Flask backend web application
- `templates/index.html` - web app frontend template
- `static/css/style.css` - web app styling
- `static/js/app.js` - web app frontend logic
- `static/vendor/pose.js`, `camera_utils.js`, `drawing_utils.js` - local MediaPipe JS dependencies
- `dist/squat_trainer.exe` - built Windows executable (generated by PyInstaller)
- `requirements.txt` - Python dependencies
- `build.bat` / `build.ps1` - build helpers for packaging
- `build_installer.bat` / `build_installer.ps1` - installer packaging helpers
- `squat_trainer.spec` - PyInstaller spec file generated during packaging

## Run directly with Python
1. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
2. Run the trainer:
   ```powershell
   python squat_trainer.py
   ```

## Run the web application
1. Install requirements:
   ```powershell
   python -m pip install -r requirements.txt
   ```
2. Run the Flask server:
   ```powershell
   python app.py
   ```
3. Open `http://127.0.0.1:5000` in your browser.

The web UI loads MediaPipe dependencies from local static files, so it works without CDN access.

### Privacy and session cleanup
- Session data is only stored when you click **Save Session**.
- Saved sessions appear in the history panel.
- You can delete individual sessions with the **Delete** button.
- Use **Clear History** to remove all stored session data after you finish.

## Run with Docker
1. Build the Docker image:
   ```powershell
   docker build -t ai-squat-trainer .
   ```
2. Run the container:
   ```powershell
   docker run --rm -p 5000:5000 -v ${PWD}:/app ai-squat-trainer
   ```
3. Open `http://127.0.0.1:5000` in your browser.

## Run with Docker Compose
1. Build and start the app:
   ```powershell
   docker-compose up --build
   ```
2. Open `http://127.0.0.1:5000` in your browser.

## Run the packaged executable
1. Build a standalone executable:
   ```powershell
   .\build.bat
   ```
2. The executable will be created at `dist\squat_trainer.exe`.

## Build an installer
1. Install [Inno Setup](https://jrsoftware.org/isinfo.php).
2. Run the installer build helper:
   ```powershell
   .\build_installer.bat
   ```
   or
   ```powershell
   .\build_installer.ps1
   ```
3. The installer will be created at `squat_trainer_installer.exe`.

## Web app deployment options
- To test locally, use the Flask app first.
- To deploy to a cloud host, use the included `Dockerfile` and `docker-compose.yml`.
- You can deploy to Render, Railway, or DigitalOcean App Platform using the container or the Python process directly.

## Desktop app deployment
- The desktop mode is the file `squat_trainer.py`.
- Use `build.bat` to create a portable `.exe`.
- Use `build_installer.bat` to create a Windows installer.

## Controls
- `Q` / `ESC` - Quit
- `R` - Reset counter
- `S` - Toggle stats
- `C` - Calibrate standing pose
- `D` - Toggle dataset recording

## Deployment notes
- The built executable is already available in `dist\squat_trainer.exe`.
- The app downloads the MediaPipe pose model on first run and stores it in a temporary directory.
- If you want a portable deployable app bundle, copy the `dist` folder and include `squat_dataset.csv` after running.
